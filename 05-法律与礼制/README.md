# 05 法律与礼制

「礼」与「法」如何共同规定行为：出礼入刑、亲属容隐、八议十恶。

## 条目地图

- **礼法关系** — 「礼之所去，刑之所取」；德主刑辅的谱系，《唐律疏议》「一准乎礼」之评。〔待写〕
- **历代法典** — 《法经》 → 汉《九章律》 → 《唐律疏议》 → 《宋刑统》 → 《大明律》 → 《大清律例》。〔待写〕
- **刑罚体系** — 五刑演变：肉刑 → 笞杖徒流死；凌迟等法外之刑及其争议。〔待写〕
- **身份与减免** — 八议、官当、十恶、亲属容隐、服制定罪。〔待写〕
- **司法程序** — 州县自理 → 审转复核 → 秋审朝审；死刑复核。〔待写〕
- **五礼** — 吉凶军宾嘉；冠婚丧祭的国家规定与民间实践。〔待写〕
